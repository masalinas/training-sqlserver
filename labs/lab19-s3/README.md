## Introducción

Copia a S3 (Backup to URL for S3): El comando nativo de copias de seguridad amplía su alcance más allá de Azure. Ahora permite ejecutar BACKUP DATABASE y RESTORE directamente contra cualquier almacenamiento de objetos compatible con la API de Amazon S3, ya sea en la nube pública (AWS, GCP) o en infraestructuras locales (como MinIO).
