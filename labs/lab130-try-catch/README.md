## Introducción

Introducción del manejo estructurado de excepciones directamente en Transact-SQL (T-SQL). Permitió a los desarrolladores capturar y gestionar errores de forma limpia, similar a lenguajes como C# o Java, superando la antigua necesidad de comprobar la variable @@ERROR tras cada instrucción.

## Ejemplos

Ver la sql: `try_catch.sql` desde SQL Server Management Studio.
